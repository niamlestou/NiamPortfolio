The Problem

Markets move all day, and good trading asks for the same things every time: research, a plan, and the discipline to follow it. Doing that by hand is slow, emotional, and easy to skip when life gets busy. Most people either miss the setup or talk themselves into a bad one.



Currently, the problem is that Day Trading as a practice almost always loses in the long run, and that is just because of the volatility of the markets. The AI has not yet made money in any version of it or in any trial run not because it's bad or its training is bad, but rather because I haven't found a way to apply it to financial data in a way that puts it in a position to win. I'm currently trying to change the way the AI approaches the data, and change the way that Qwen and Laya interact with each other, and the market. The problem is I want to make money from the stock market with AI in a way that can outperform a computer script with pre-written rules, and have not been able to find that path yet. If you have any ideas, PLEASE contact me.

Key Decisions

01

Trained Models, Not a Chat Wrapper

A general chatbot can talk about the market, but it was not trained to trade it. Tick Forward uses models trained on market data, so decisions are faster, cheaper, and repeatable.

02

Multiple Types of Models

LLMs and SLMs are pretty slow for decisions on a market that is rapidly changing moment to moment. When every second matters, you need quick decisions. Laya is an open-source system 1 model (Like Jev) that can be run locally and is very fast. The catch is that it needs to be calibrated and sometimes trained so that it can make the right decisions confidently, which is where much of my learning is coming from.

03

Automation With Guardrails

Automation is only useful if it is safe. The model proposes and the rules dispose: risk limits and position sizing sit between the signal and the order, with a clear testing path before real money is involved.

Under the Hood

01

Numbers to a Logistic, Text to Laya

A ridge logistic model read the market snapshot numbers far better than Laya did (regime AUC 0.925 vs 0.631), so numbers go to the logistic. Laya reads text and breaks ties where the logistic is unsure. New kinds of data go to the logistic first.

02

Fine-Tuning Qwen With QLoRA

I fine-tuned Qwen3-4B-Instruct with 4-bit QLoRA in PyTorch (peft and bitsandbytes) to read a headline and call its direction. The answer is one word, scored from the first-token probabilities, so the base and tuned models compare without any sampling noise.

03

Honest Evaluation

The tuned model jumped from 71% to 88% accuracy on public sentiment data, but on 6,000 held-out Benzinga headlines labelled by what the stock did next, the AUC gain was +0.004 with an interval spanning zero. That is not a win, and the report says so. A model only counts if it beats the base on time-split data it never trained on.

04

Lookahead and Cost Guardrails

Headlines must be created before the entry open, and the tuned model is only tested after its last training day. A fitted Laya on 25 large caps reached ECE 0.02 to 0.06 but no measured edge. Hard limits cap each position at $5,000 and daily loss at $250, on a paper account until the evidence is there.

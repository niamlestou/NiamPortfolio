The Problem

All of the websites and projects that I build have as many analytics and measurements as I can get away with. The demo above shows why.

There was a bug in my weather forecast engine, and when it failed, it failed quietly. No alerts went off and nothing broke. But the result was that it was calling Claude an absurd number of times, which could have led to huge API costs!

Thankfully, a gate already written into the code did not allow any tokens to be used from an engine that had failed. Still, calling Claude that many times was not ideal. Because of this dashboard and the data it reported, I was able to catch it and fix it!
